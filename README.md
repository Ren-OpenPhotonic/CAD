## ✨ 核心特性 (Features)

### 1. 🧱 像搭乐高一样直观：纯三维实体布尔建模 (Pure CSG)
* **告别 2D 草图约束报错**：无需面对传统 CAD 繁琐的基准面与草图欠约束/过约束噩梦，直接在 3D 空间放置长方体、圆柱体、球体、棱柱等基础几何体；
* **极速布尔运算**：实心体为“加法”，切削孔为“减法”，底层杜绝脆弱的非线性相交计算，**永远不崩溃、永远不死机飘红**。

### 2. 🏷️ 制造语义出生即绑定 (Model-Based Definition / MBD)
* 在定义几何体尺寸的同时，原生绑定**尺寸公差**、**表面粗糙度 (Ra/Rz)** 与 **形位公差 (GD&T)**；
* 支持指定测量**基准 (Datum A/B/C)**，支持两面平行度、垂直度、同轴度等工艺关联标注；
* 左上角悬浮仿 SolidWorks 交互式设计树，所有面、线、点、轴线清晰可查，点击即高亮。

### 3. 📐 一键生成符合国标 (GB/T) 的标准 A4 机械工程图 (PDF)
* **标准第一角三视图**：自动生成正视图、俯视图、左视图，严格遵循“长对正、高平齐、宽相等”对齐准则；
* **告别杂乱三角面对角线**：采用纯正机械轮廓投影，平面绝对干净，切削孔与槽口真实咬合；
* **全套国标标题栏与技术要求**：包含零件图号、材料（45#钢、6061铝等）、比例、设计签名与去毛刺/未注公差标准条款，**直接输出车间可投产的标准 PDF 蓝图**！

### 4. 🖨️ 3D 打印无缝支持 (STL Export)
* 一键导出标准的二进制 `.stl` 实体文件，封闭流形网格，可直接拖入拓竹 Bambu Studio、Cura 或三维切片软件中打印。

## 🚀 极客设计哲学 (Design Philosophy)

1. **奥卡姆剃刀定律**：如果长方体、圆柱体和倒角就能解决 90% 的机械结构件加工，就坚决不引入庞大臃肿又容易崩溃的 200 万行自由曲面内核。
2. **零服务器负担**：纯前端静态架构（HTML5 + WebGL + Three.js + three-bvh-csg），所有三维运算 100% 跑在用户本地浏览器或显卡中，零延迟、零数据泄露风险。
3. **制造导向**：图纸是给车间工人看的，不是给工程师做智力题的。横平竖直、尺寸清晰是工程图的最高准则。
